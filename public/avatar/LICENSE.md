# MPFB avatar

Source: https://github.com/met4citizen/TalkingHead/blob/main/avatars/mpfb.glb
Downloaded 2026-09-25. The upstream TalkingHead README explicitly licenses this
example avatar under CC0: https://github.com/met4citizen/TalkingHead#credits
CC0 deed: https://creativecommons.org/publicdomain/zero/1.0/

Local modifications: embedded textures resized to at most 1024 pixels and recompressed; added a neutral zero-displacement `viseme_sil` morph target.
The upstream file contains 52 ARKit shapes and 14 non-silent Oculus visemes.
No Ready Player Me, Avaturn, AvatarSDK or VRoid example is distributed here.
